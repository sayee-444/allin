## Agent skills

### Issue tracker

Los issues se registran en GitHub Issues (sayee-444/allin) con el CLI `gh`. See `docs/agents/issue-tracker.md`.

### Issue workflow

El agente supervisa el roadmap: sigue el orden de `docs/roadmap.md`, implementa, prueba, guarda evidencia y cierra los issues. See `docs/agents/issue-workflow.md`.

### Triage labels

Etiquetas por defecto: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: un `GLOSSARY.md` y `docs/adr/` en la raíz del repo. See `docs/agents/domain.md`.
